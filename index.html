Publier en ligne

Pour mettre à jour le site et l'appli de tout le monde :

  1. Chargez d'abord le nouvel Excel ci-dessus.
  2. Touchez « Exporter » pour télécharger planning-data.json.
  3. Déposez ce fichier sur GitHub (il remplace l'ancien).
